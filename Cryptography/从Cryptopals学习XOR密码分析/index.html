破译步骤：

  1. base64 解码得到密文字节。
  2. 猜测 keysize。
  3. 用 Hamming distance 评价 keysize。
  4. 按 keysize 把密文转置。
  5. 每一列当作单字节 XOR 解。
  6. 拼出完整 key。
  7. 用 key 解密全文。

8. 常见问题

8.1 在字符串上直接 XOR

不要在编码字符串上直接操作。正确流程是：

8.2 英文评分太粗糙

评分函数不需要完美，但要能明显区分英文文本和乱码。空格权重要高，不可打印字符要重罚。

8.3 只用前两块猜 keysize

只比较前两块可能误差较大。可以取前几块两两比较后求平均。

9. 小结

Cryptopals Set 1 的 XOR 题虽然基础，但训练了密码学实验里很重要的几个习惯：

  1. 一切先转 bytes。
  2. 每个函数用平台样例验证。
  3. 候选结果要排序，不要凭感觉选。
  4. 运行结果要能复现。

后面做 AES、CBC、RSA 时，这些习惯仍然有用。
