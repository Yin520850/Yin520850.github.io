1. 分组密码为什么需要填充

AES 的 block size 是 16 字节。也就是说，AES 单次只能处理 16 字节的数据块。

7. 常见问题

7.1 把 IV 当成 key

IV 和 key 不是同一个东西。key 是保密的，IV 通常可以公开，但 CBC 的第一块解密需要 IV。

7.3 padding 没校验

去 padding 时不能只看最后一个字节，还要检查最后 pad_len 个字节是否完全一致。

8. 小结

PKCS#7 和 CBC 都是分组密码里很基础但很容易写错的部分。

复现时建议按这个顺序做：

  1. 先写 padding。
  2. 再写单块 AES。
  3. 再写 CBC 链接。
  4. 最后用平台真实文件解密验证。

这样每一层都有证据，调试也更容易。
