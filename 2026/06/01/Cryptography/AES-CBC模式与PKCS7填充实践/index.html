为什么要自己实现 CBC

实验中没有直接调用库的 CBC 模式，而是自己实现 ECB block 和 XOR 链接。这样可以清楚看到 CBC 的两个性质：

  • 同样的明文块在不同位置通常不会产生同样的密文块。
  • 修改某一块密文会影响当前块解密，并在下一块产生可控 bit flip。

第二点正是 CBC bit flipping attack 的基础。

实验建议

写这类实验时，最好按以下顺序验证：

  1. 先验证 PKCS#7 样例。
  2. 再用 AES 单块测试确认 ECB 基元。
  3. 再解 Cryptopals 的 CBC 数据文件。
  4. 最后实现 oracle 或攻击类题目。

这样每一层都有证据，不会在最后才发现底层字节序或 padding 错了。
