密码学实验复现如何保证真实可信

密码学实验最怕两件事：一是用自己编的小数据假装完成，二是截图和代码对不上。为了避免这两个问题，我把本次实验拆成了证据、代码、运行日志和截图四类材料。

证据先行

所有公开题面先保存到本地：

  • Cryptopals Set 1 / Set 2 页面。
  • Cryptopals challenge-data 文件。
  • MysteryTwister C3 的 SHA1 和 ePassport PDF。
  • Project Euler 182 页面。
  • RSA 破译题本地 PDF 和 Frame 附件。

这样报告里每个输入都能追到来源，而不是从记忆里复制。

报告写作原则

我认为实验报告应该遵守三个原则：

  1. 题目数据不改。
  2. 代码和运行截图一致。
  3. 未恢复或不确定的结果明确说明，不为了完整而补写。

尤其是 RSA 破译题，当前只恢复了数学关系可以证明的分片。未恢复的 Frame 没有强行编成完整句子，这是比“看起来完整”更重要的真实性。

小结

好的实验报告不只是把答案贴出来，而是让读者能沿着“题面 -> 数据 -> 代码 -> 测试 -> 运行 -> 截图”完整复查。密码学尤其需要这种习惯，因为一个字节、一个填充位、一个参数复用，都可能决定结果完全不同。
